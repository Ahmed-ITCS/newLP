# newLP

Landing page for Penta Cipher Technologies.

The site lives in `penta-react/` (Vite + React) and includes a serverless
contact endpoint in `penta-react/api/` that creates leads in GoHighLevel.

## Local development

```bash
npm install
npm run dev
```

## Production

Deploy the `penta-react` directory to Vercel and set the environment variables
listed in `penta-react/.env.example`.
